**FUND FIT AI** is an institutional-grade, AI-powered Mutual Fund & Wealth Intelligence Platform. Built for individual investors, wealth management firms, and SEBI-registered financial advisors (RIAs), it combines **Explainable AI (XAI)**, **Adaptive Benchmarking**, **Market Regime Detection**, and **Goal Simulator Engines** into a unified SaaS experience.

---

## ✨ Key Platform Features

### 1. 🌐 Luxury SaaS Marketing Landing Page
- Sticky header with glassmorphism, glowing hero section, live floating portfolio preview card, stats banner (100k+ investors, 25k+ funds), product module showcase, pricing plans, and book demo modal.

### 2. 🔐 Enterprise SSO & MFA Security Portal
- Full login, registration, password recovery, OAuth 2.0 (Google, Microsoft, Apple), and 2-Factor Authentication (2FA) verification interface.

### 3. 📊 Investor Wealth Command Center
- Real-time KPI metrics: Portfolio Value (₹24.85L), Portfolio XIRR (18.4%), Fund Fit Score (92/100), and Goal Completion Probability.
- Active Mutual Fund holdings tracker (PPFAS Flexi Cap, HDFC Top 100, Quant Small Cap, Mirae Asset) with SIP schedules.

### 4. 🧭 Mutual Fund Explorer & Comparison Studio
- AMFI registry search engine covering **25,000+ mutual fund schemes**.
- Filter by AMC, category (Flexi Cap, Small Cap, Large Cap, Mid Cap), risk profile, and expense ratio.
- Detailed modal breaking down NAV, 3Y CAGR, top stock holdings, sector allocation, and AI signal reasoning.

### 5. 🎯 Adaptive Goal Planning Engine
- Goal projection simulators for Retirement (₹5Cr), Real Estate (₹1.5Cr), and Education (₹50L) with timeline and monthly SIP sliders.

### 6. 🌐 Macro Market Intelligence & Regimes
- Real-time market indices: NIFTY 50 (24,180.50), SENSEX (79,450.20), INDIA VIX (14.25).
- Sector momentum matrix and institutional FII/DII net liquidity flows.

### 7. 🧠 Explainable AI (XAI) Recommendation Engine
- Transparent Buy, Hold, Switch, and Exit signals backed by verifiable risk-reward math and currency hedging logic.

### 8. 🏢 Advisor & Admin Portals
- **Advisor Portal**: Client AUM management (₹14.2Cr total AUM), portfolio health audits, and proposal generator.
- **Admin Portal**: AMFI master feed sync status (25,410 schemes), cluster logs, and security audit stream.

### 9. ⌘ Global Command Palette & 🤖 24/7 AI Chatbot
- Keyboard-driven shortcut search (`Ctrl+K` or `Cmd+K`) across funds and pages.
- Natural language mutual fund assistant drawer.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `yarn`

### Installation & Local Run

```bash
# 1. Clone the repository
git clone https://github.com/techspartan90-lang/FundFit-AI.git

# 2. Navigate to project directory
cd "Fundfit AI"

# 3. Install dependencies
npm install

# 4. Start Vite development server
npm run dev
```

Open `http://localhost:5173/` in your browser to view the live application.
